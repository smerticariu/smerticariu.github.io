Installing

How do I install it?

With Homebrew: brew install --cask smerticariu/tap/my-terminal. Or open MyTerminal-1.0.1.dmg, drag My Terminal to Applications and open it from there. It runs on macOS 14 Sonoma or later, on Apple silicon and Intel Macs.

macOS asks whether My Terminal may access Documents, Desktop or Downloads.

That's macOS protecting those folders; it asks once per folder, the first time a command reads it. Choose Allow so ls, git and your tools work there. You can change it later in System Settings → Privacy & Security → Files and Folders.

How do I update?

With Homebrew: brew upgrade --cask my-terminal. Otherwise download the new DMG from the My Terminal page and replace the app in Applications. The app never checks for updates on its own — it makes no network connections.

How do I uninstall it?

Quit it and move it from Applications to the Trash. With Homebrew, brew uninstall --zap --cask my-terminal also removes its settings, saved tabs and command journal.

Shells and settings

Which shell does it use? Where do my aliases come from?

Your login shell, normally zsh, reading your usual files: ~/.zshenv, ~/.zprofile, ~/.zshrc (oh-my-zsh, aliases, PATH). bash and fish work too and can be picked in Settings → General. After editing ~/.zshrc, open a new tab or run source ~/.zshrc.

I'd rather type straight into the shell.

View → Modern Input Editor (⇧⌘I) switches to classic input. Settings → Input also lets you keep your own shell prompt.

Where are the settings stored?

Only on your Mac: ~/Library/Preferences/dev.smerticariu.myterminal.plist, and workflows and custom themes in ~/Library/Application Support/My Terminal.

Troubleshooting

Commands don't show as blocks.

Blocks need the shell integration, which loads automatically for zsh, bash and fish. Other shells (sh, nu…) run in classic mode. If you use a custom ZDOTDIR, make sure it's exported before My Terminal starts.

A secret in my output is hidden and I need it.

Click the covered text to show it, or right-click → Copy Including Secrets. Turn hiding off in Settings → Security.

Tab completes nothing for a command.

Argument completion comes from zsh's own completion functions. If zsh itself has none for that tool, My Terminal falls back to files and folders.
