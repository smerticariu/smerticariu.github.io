Your shell, with blocks.
And nothing leaves your Mac.

My Terminal is a native macOS terminal: every command becomes a block you can copy, rerun or open, you type in a real editor, and Tab gives you zsh's own completions. No account, no cloud, no AI.

Download for Mac

Version 1.0.3 · macOS 14 Sonoma or later · Apple silicon and Intel · Free

or with Homebrew:

brew install --cask smerticariu/tap/my-terminal
▦

Command blocks

Each command with its output, exit code and duration. Copy the output, run it again, or open it in a searchable window.

✎

A modern input editor

Click to move the cursor, select with the mouse, several lines with ⇧↩, syntax colours and suggestions from your history.

⇥

Feels like zsh

Tab uses zsh's own completion (git, kill, ssh, brew…), your aliases, !! and !$, and the zle keys you know.

◫

Tabs, splits, sidebar

Named and coloured tabs, split panes, a command palette (⇧⌘P), saved workflows, and your window on a global shortcut.

↗

Clickable output

Click a folder to cd into it, or file.ts:42 to open it at that line in your editor.

🛡

Built for work

Secure keyboard entry at password prompts, paste protection, secrets hidden in output, and red zones for production.

Private by design

My Terminal has no networking code at all: no account, no analytics, no crash reports, no updates checking in the background, no AI. What you type and what your commands print stay on your Mac. Read the privacy policy.

Install

With Homebrew — no download page, and updates with brew upgrade --cask my-terminal:

brew install --cask smerticariu/tap/my-terminal

Or by hand:

  1. Download MyTerminal-1.0.3.dmg and open it.
  2. Drag My Terminal to Applications, then open it from there.
  3. The first time a command reads your Documents or Desktop, macOS asks once for permission — choose Allow.

The app is signed with an Apple Developer ID and notarized by Apple.
